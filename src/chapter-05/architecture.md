# 5.1 整体架构：三个进程

```
┌─────────────────────────────────────────────────────────────────┐
│                         你看到的浏览器页面                        │
│              http://localhost:6274  (MCP Inspector UI)           │
└──────────────────────────┬──────────────────────────────────────┘
                           │ HTTP / fetch
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│                   前端 HTTP 服务器                                │
│         client/bin/client.js  (端口 6274, Express 静态托管)        │
│         将前端资源（HTML/CSS/JS）提供给浏览器                      │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 进程间通信（spawn）
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│                   后端代理进程                                    │
│         server/build/index.js  (端口 6277, Express 服务器)        │
│         接收浏览器请求，调用 MCP SDK，转发到 stdio                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │ stdio (stdin/stdout 管道)
                           ↓
┌─────────────────────────────────────────────────────────────────┐
│                   MCP Server 子进程                              │
│              node obsidian-mcp-server.js                         │
│              执行业务逻辑：读取 Obsidian 笔记文件                  │
└─────────────────────────────────────────────────────────────────┘
```

**这三层全部跑在你自己的电脑上，没有外网请求。**
